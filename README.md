# SIP & Investment Calculator 💰

Comprehensive investment planning tool —
SIP, lumpsum, goal planner and retirement calculator.

## Live Demo
[Click here](https://sip-calculator-7pmxqjvdzzyhwuaize7sdy.streamlit.app)

## Features
- SIP calculator with step-up option
- Year-wise breakdown table
- Lumpsum calculator with inflation adjustment
- Rule of 72 calculator
- Goal-based planner (house, education, wedding)
- Retirement corpus calculator
- Mutual fund category comparison
- All calculations in Indian Rupees

## Financial Concepts Covered
- SIP, CAGR, Corpus
- Inflation-adjusted returns
- Real rate of return
- Income replacement ratio
- Rule of 72

## Tools Used
- Python, Streamlit, Plotly, Pandas, NumPy

## How to Run Locally
pip install streamlit pandas numpy plotly
streamlit run app.py
